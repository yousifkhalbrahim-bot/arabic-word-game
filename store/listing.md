# نصوص صفحة المتجر (App Store Connect)

انسخها كما هي في App Store Connect ← التطبيق ← اللغة العربية.

## الاسم (30 حرف كحد أقصى)
لعبة الكلمات

## العنوان الفرعي (30 حرف)
تحدّى أصحابك بالكلمات العربية

## النص الترويجي (170 حرف)
ثلاث ألعاب كلمات عربية في تطبيق واحد: ساعة الشطرنج، سباق الكلمات، وخمّن الكلمة. العبها لحالك أو تحدّى صاحبك أونلاين!

## الوصف
لعبة الكلمات = ثلاث ألعاب عربية ممتعة، وكل لعبة تقدر تلعبها لحالك أو مع صاحبك.

⏱ ساعة الشطرنج
نهاية وحدة للجولة كلها، وكل واحد يكتب كلمة بدوره قبل ما تخلص ساعته. العبها ضد الكمبيوتر، أو مع صاحبك أونلاين، أو على نفس الجوال.

⚡ سباق الكلمات
كل سؤال نهاية مختلفة، وأول واحد يكتب كلمة صحيحة ياخذ النقطة. جمّد خصمك أو تجاوز السؤال! أو تدرّب لحالك ضد الوقت وسجّل رقمك القياسي.

🟩 خمّن الكلمة
اكتشف الكلمة المخفية بالألوان: الأخضر حرف صح بمكانه، والبرتقالي حرف موجود بمكان ثاني. كلمة جديدة كل يوم، بثلاث مستويات (3 و4 و5 أحرف)، أو تحدّى صاحبك على نفس الكلمة واللي يحلها بمحاولات أقل يفوز.

✨ المميزات
• قاموس عربي بأكثر من 1700 كلمة
• لعب أونلاين برابط دعوة تشاركه على الواتساب
• بدون تسجيل دخول، بدون إعلانات
• الألعاب الفردية تشتغل بدون إنترنت

## الكلمات المفتاحية (100 حرف، مفصولة بفواصل بدون مسافات)
كلمات,عربي,ألغاز,تخمين,حروف,تحدي,أصدقاء,سباق,قاموس,لغة,ذكاء,ترفيه,عائلة

## التصنيف
- الأساسي: ألعاب ← كلمات (Word)
- الثانوي: ألعاب ← ألغاز (Puzzle)

## التصنيف العمري
4+ (اختر "لا" لكل الأسئلة)

## روابط

## خصوصية التطبيق (App Privacy)
- Data collection: **Yes** ← User Content → Other User Content (الاسم المستعار داخل غرفة اللعب)
  - Linked to user: **No** — Used for tracking: **No** — الغرض: App Functionality
- أو إذا تبي أبسط: Data Not Collected (الأسماء مستعارة ومؤقتة) — الأدق هو الخيار الأول.

## ملاحظات للمراجع (App Review → Notes)
اللعبة لا تحتاج تسجيل دخول. لتجربة اللعب الجماعي: افتح أي لعبة ← "مع صاحبك" ← إنشاء غرفة، ثم افتح التطبيق على جهاز ثاني ← "عندك كود غرفة؟" وأدخل الكود. الألعاب الفردية (خمّن الكلمة، التدريب، ضد الكمبيوتر) تعمل مباشرة.
