# نصوص صفحة المتجر (App Store Connect)

انسخها كما هي في App Store Connect ← التطبيق ← اللغة العربية.

## الاسم (30 حرف كحد أقصى)
لعبة الكلمات

## العنوان الفرعي (30 حرف)
تحدّى أصحابك بالكلمات العربية

## النص الترويجي (170 حرف)
لعبتين كلمات عربية في تطبيق واحد: تحدي النهايات وخمّن الكلمة. العب لحالك أو تحدّى صاحبك أونلاين، واجمع نقاط وتصدّر الترتيب!

## الوصف
لعبة الكلمات = لعبتين عربية ممتعة، وكل وحدة تلعبها لحالك أو مع صاحبك.

🟧 تحدي النهايات
اكتب كلمات تنتهي بحروف معيّنة قبل ما يخلص وقتك.
• لحالك: ضد الكمبيوتر بالدور، أو ضد الوقت وسجّل رقمك القياسي.
• مع صاحبك: بالدور ولكل واحد ساعته، أو سباق — أول واحد يكتب الكلمة ياخذ النقطة، مع تجميد الخصم وتجاوز السؤال.

🟩 خمّن الكلمة
اكتشف الكلمة المخفية بالألوان: الأخضر حرف صح بمكانه، والبرتقالي حرف موجود بمكان ثاني.
• ٣ أحرف (أسهل) أو ٥ أحرف (أصعب)، مع تلميحات وستريك.
• مع صاحبك: خمّنوا نفس الكلمة واللي يحلها بمحاولات أقل يفوز، أو اختر له كلمة سرية (ومعها تلميح) وتفرّج عليه وهو يخمّن!

🏆 النقاط والترتيب
كل فوز يعطيك نقاط، وتنافس على ترتيب الأسبوع والترتيب العام.

✨ المميزات
• أكثر من 20 ألف كلمة عربية
• لعب أونلاين بكود أو رابط دعوة على الواتساب
• بدون تسجيل دخول، بدون إعلانات
• أصوات واحتفالات واهتزاز

## خصوصية التطبيق (App Privacy)
- Data collection: **Yes**
  - User Content → Other User Content (الاسم المستعار + الكلمة السرية داخل غرفة اللعب)
  - Identifiers → User ID (معرّف عشوائي للجهاز عشان النقاط والترتيب)
  - Linked to user: **No** — Used for tracking: **No** — الغرض: App Functionality
